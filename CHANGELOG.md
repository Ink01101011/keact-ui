## [0.1.0] - 2026-02-25

### Added
- Initial project setup with Vite, TypeScript, and React
- ESLint configuration for code quality
- Prettier configuration for code formatting
- Jest and React Testing Library for testing
- Storybook for component documentation
- Husky and lint-staged for pre-commit hooks
- Build optimization with bundle size visualization
- npm publishing configuration
- Button component with variants (primary, secondary, outline, ghost)
- Button sizes (sm, md, lg)
- Button states (loading, disabled, fullWidth)
- Comprehensive test suite for Button component
- Storybook stories for Button component
- Full TypeScript support with type definitions
- Documentation (README, CONTRIBUTING, QUICK_START, RELEASE_PLAN)

### Infrastructure
- Vite configuration for library build
- TypeScript configuration with strict mode
- ESLint with React and TypeScript plugins
- Prettier for consistent code style
- Jest configuration with jsdom environment
- Storybook 8 with React and Vite integration
- Husky pre-commit hooks with lint-staged
- Rollup bundle size analyzer
